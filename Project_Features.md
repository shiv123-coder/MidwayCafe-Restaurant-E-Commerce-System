# ✨ Project Features — MidwayCafe

A comprehensive overview of the features implemented in the MidwayCafe Restaurant E-Commerce System.

## 👤 User Features
- **OTP Registration**: Secure signup process using email-based One-Time Passwords.
- **Menu Browsing**: Filterable and searchable menu categories for easy food discovery.
- **Profile Management**: Personalized user dashboard to manage account details and view order history.
- **Ratings & Reviews**: Customer feedback system to rate food items and leave reviews.
- **Dark/Light Mode**: Seamless UI switching for better visual comfort.

## 🛒 Order & Cart System
- **Interactive Cart**: Real-time cart updates with AJAX-based additions and removals.
- **Coupon System**: Dynamic discount application via customizable coupon codes.
- **Tax & Charges**: Automatic calculation of extra charges and delivery fees.
- **Order Tracking**: Live status updates for orders from placement to delivery.

## 💳 Payment Integration
- **Multi-Gateway Support**: Integrated with bKash and SSLCommerz for secure online transactions.
- **Cash on Delivery**: Traditional payment option for customers who prefer offline payment.
- **Demo Mode**: Simplified payment simulation for testing and demonstration purposes.

## 🧑💼 Admin Dashboard Features
- **Operational Analytics**: Real-time summary of sales, orders, and customer activity.
- **Menu Management**: Full CRUD system for food items, categories, and pricing.
- **Chef & Staff Management**: Dedicated section to manage kitchen staff and their profiles.
- **UI Customization**: Admin tools to update banners and system settings without code changes.

## 🚚 Delivery & Shipment Features
- **Invoice Generation**: Automated PDF invoice creation and email delivery upon payment.
- **QR Code Verification**: Scannable QR codes on invoices for order verification.
- **Shipment Tracking**: Lifecycle management for delivery status (Pending, Shipped, Delivered).
- **Delivery Boy Assignment**: Tools to manage delivery staff and track their assignments.

## 📊 Reports / Analytics
- **Sales Insights**: Detailed overview of revenue and popular menu items.
- **Order History**: Comprehensive logs of all transactions and customer interactions.
